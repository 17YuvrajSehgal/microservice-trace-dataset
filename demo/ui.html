What was recorded

The raw trace for this run is 15 GB. What you are browsing is the index the agent's tools actually read: one row per 100 ms bucket per (event, process, container), built by a single decode of the whole trace.

Event rate across the recording

Every kernel event carries the namespaces of the task that produced it. pid_ns is one number per container — the only thing in a kernel trace that tells java in one container from java in another.

Containers seen

The blueprint's deciding check, computed live

The network blueprint says: sum network events per container over a quiet window and a suspect window, divide, and rank lowest first. Drag on the chart to choose the suspect window — the baseline takes the quiet stretch before it.

Try the other signals. If a container separates on network and not on CPU or scheduling, the impairment is on its network path and not the machine being busy — which is the distinction the blueprint exists to make.

Blueprint library

A blueprint is a diagnostic procedure whose every check has a measurement behind it. A validator rejects any check that does not. These are the exact files handed to the agent.
