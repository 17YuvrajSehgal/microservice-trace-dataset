Blueprint library

A blueprint is a diagnostic procedure whose every check has a measurement behind it. A validator rejects any check that does not. These are the exact files handed to the agent.

Investigation

The agent receives the kernel trace and a set of read-only analysis tools. It plans the work, runs it in parallel, writes and runs its own code, records findings with evidence, and commits to a root cause — then you can question it and point it at your source.

Run the agent starts a live investigation (two to four minutes); each step is recorded as it happens. Replay re-plays a past investigation instantly.
